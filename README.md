# Rui Portfolio

Ruiのポートフォリオサイトです。

A portfolio site for Rui.

## URL

https://rui-portfolio-azure.vercel.app

## 構成 / Sections

- Hero
- About
- Skills
- Works
- Contact

## 技術スタック / Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Formspree（コンタクトフォーム）

## 機能 / Features

- 日本語・英語の言語切り替え
- スクロールアニメーション
- レスポンシブデザイン（スマホ対応）
- コンタクトフォーム

## ローカル起動 / Getting Started

```bash
git clone https://github.com/ruik0321/rui-portfolio.git
cd rui-portfolio
npm install
npm run dev
```
